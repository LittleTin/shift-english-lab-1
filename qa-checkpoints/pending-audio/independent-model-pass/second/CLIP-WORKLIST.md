The 85 pending questions share 52 distinct, SHA-bound source windows across
41 numbered groups. Their base, one-pass playback time is approximately
1,222 seconds (about 20 minutes), not an estimated time to finish QA.
Review will take longer when words require repeats, contrast examples, or
matched comparison in both modes. Deduplication is only for identical
asset URL and interval; formal and practice mappings remain separately
labeled in each target. Does not authorize recording, uploads, changed
audio or any verified status.

clip-worklist-index.json points to one file per exam. Rebuild using
plan_clip_review.py with a fresh pinned refresh_remaining.py index and
scoped real assets (--assets). A target records exact number, protected
already verified siblings, original versioned focus/passage role, source
audio hash and boundaries. Already verified siblings are excluded from
counts and must not be replaced or reopened by accident. No media copies
are included. Prepare only small from/to clips for any explicitly
authorized later reviewer; the log can capture multiple listeners or
independent evidence. Keep fail-closed decisions separate from typed draft
replacements; compare written options, actual audio, browser time and
versions before promotion.
