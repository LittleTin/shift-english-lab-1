# Scoped adopted audio composition checkpoint

Requires Python 3.12+ (tar data extraction filter), Git, FFprobe and local Git objects for pinned work commit fa6e3f8fa86a6b8f701dc4574db32bdbdc35cb01 and prior deployed release 043b91761f63062708d70f7cda3a6b2046cd4cf9. Run:

    python3 compose.py --repo /path/to/repo --out /absent/path/outside/repo

The script extracts exact inputs via git archive. Output site contains only scratch packs and hydrated media, no publishable shell. Work and prior refs are read-only. It verifies all 13 exact ledger question/group/range/asset roles and hashes, replays overlays in order, checks their existing before/after SHA guards, verifies no other questions or groups changed and all previous/alternate/legacy snapshots retained, regenerates JS and invokes the official validator. It writes proof.json only after success.

This is the source-to-active scoped audio composition, not the complete authoring integration or browser acceptance. Do not deploy it or append historical active copies to the new practice pool.
