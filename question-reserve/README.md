# SHIFT 候用題庫

本目錄是工作分支上的持久備份，不是現行題庫、正式發行內容或已完成的第四回。唯一專案規格以根目錄 SHIFT-SPEC.md 為準。

- 一個目錄保存一題獨立題或一個完整題組；包含題組原文、各題雙語題源、原始驗證和來源雜湊。未另行標記為移出現行題庫前，`saved-pending-replacement` 表示原題仍在原回次，這裡只是一份可復原備份，不可分配到新回。
- 換下原題時須先核實新題完整驗證、舊題也已持久保存。只有原題不再是現行使用單位、且不會和現行題重複時，才能將狀態轉為候用。媒體須以實際檔案或可驗證的不可變來源保存；不可只寫暫存路徑或僅摘錄逐字稿。
- 將候用題移入正式題源後，須核對新回／題號、整組及音圖路徑、正式題號與時間軸、答案和雙語解析。提交、推送及確認遠端後才移除本目錄對應副本；Git 歷史可還原，舊測驗的作答與分數仍保留。
- 排除本目錄於網站輸出、現行題數、抽題、計分與第四回生產狀態。第一批都是已驗證的純文字閱讀題組，且原題尚未被替換。
