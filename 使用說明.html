這一版的內容

本版提供 3 回、共 600 題原創練習：閱讀 300 題、聽力 300 題。每回按 Part 1–7 題數配置（6、25、39、30、30、16、54），搭配繁體中文翻譯、正解說明、每選項理由、證據與詞彙。

這是第一版操作與內容樣本，更多題庫尚待擴充。Part 1 採原創情境插圖，並非正式考試照片。聽力使用美式、英式、印度及澳洲英語的離線神經合成語音；正式模考以約 45 分鐘安排錄音、題目朗讀及停頓，不是官方錄音，也未經正式難度校準。內容不是 ETS 官方試題。

比較原版與新版音訊，試聽不同口音。

同一個網址及瀏覽器設定檔更新網站時，不要清除網站資料。換網址、瀏覽器或裝置前，請先匯出備份。

正式模考

每回 200 題：聽力 100 題約 45 分鐘、閱讀 100 題 75 分鐘。正式聽力依序播放，每組一次，不暫停、快轉或回放。Part 3／4 正式題組各 3 題共置一頁。閱讀可跳題，不能返回聽力。

先完成一批，再一起檢討

  1. 選擇練習：每日抽題、分類練習、分科練習、錯題重練與整回測驗，都採整批作答。
  2. 作答與修改：逐題選擇答案，可回上一題或使用題目列表切換；交卷前不顯示正誤、正確答案、翻譯、逐字稿或解析。
  3. 交卷評分：完成後交卷，依「答對題數 ÷ 本次總題數 × 100」計算 100 分制成績。未作答題目列入總題數，並計為錯題。
  4. 檢討錯題：結果頁列出本次錯題，點選題目即可查看原題、自己的答案、正解、完整繁中解析、各選項理由、原文證據與詞彙。

例如：一批 20 題答對 16 題，成績為 80 分。這是本次練習的正確率，不是多益官方分數，也不進行 990 分制換算。

怎麼練習

功能使用方式
每日練習首頁可直接抽取約 20 題閱讀或聽力；共用文章、對話會保留題組。
分類練習依題型、科技／製造／商務／生活主題及難度篩選。
交卷與解析作答中只記錄選擇，不立即判分。交卷後顯示 100 分制成績與錯題清單，再點選錯題查看完整解析。
聽力點播放鍵。Part 1／2 作答前只顯示選項字母，避免先看到聽力內容。交卷後可在解析中查看逐字稿與繁中翻譯。
收藏與筆記點星號收藏；展開「我的筆記」輸入，會自動儲存。
錯題複習交卷時將錯題加入複習清單；錯題重練也採整批作答、交卷後解析。同題連續答對兩次後移出待複習，仍可選「所有曾錯題目」查閱。
整回測驗聽力約 45 分鐘，依序播放，每組一次；閱讀 75 分鐘，可自行跳題。交卷後才顯示評分與解析。離開頁面後計時繼續；未答題在交卷時計為錯題。

紀錄與備份

程式優先使用 IndexedDB；無法使用時嘗試 localStorage。若兩者都不可用，頁面會顯示暫存警示。這些紀錄屬於目前瀏覽器與網站位置，不會自動同步，也不會自動上傳到伺服器。

  • 請使用一般視窗；無痕模式的紀錄可能在關閉後消失。
  • 移動資料夾、更換瀏覽器、清除網站資料或更新版本之前，請先在「資料管理」匯出備份。
  • 備份包含作答、錯題、收藏、筆記、未完成練習及自行匯入的題庫；不包含網站資料夾中的音訊與圖片檔案。
  • 匯入備份會取代目前紀錄，網站會先要求你確認。請保留原備份檔。
  • 使用 file:// 時，各瀏覽器的保存策略可能不同；若紀錄沒有保留，先查看頁首保存狀態並匯出備份。

新增題目，不必修改 HTML

方式一：在網站內匯入 JSON

前往「資料管理」→「下載格式範例」。依範例填寫新題庫，使用獨立的 testId、題目 ID 與題組 ID，再按「匯入 JSON 題庫」。新增題目會顯示在目前瀏覽器的首頁，並加入分類練習。單包上限為 5,000 題與 20 MiB。

若有新增音訊或圖片，請將檔案放入此網站的 audio/ 或 assets/ 目錄，並在 JSON 中填寫相對路徑。網站不會自動把音檔從其他資料夾搬進來。

方式二：製作可攜式題庫包

發布者可使用 Python 3.9 以上執行隨包的 tools/add_pack.py。工具會驗證 JSON、轉成適合直接雙擊開啟的 JS 題庫，並更新 data/catalog.js。將更新後的整個資料夾交給別人，新題庫即可出現在首頁，不必修改 index.html，練習者也不需要安裝 Python。格式、指令與更新方式請參考 AUTHORING.md 題庫擴充指南。

手機使用

版面已針對手機設計。若要穩定地在手機使用，將整個資料夾放到一般靜態網站主機後，以瀏覽器開啟；資料夾內音檔、圖片與題庫需一起上傳。本機電腦直接開檔與手機瀏覽器的檔案開啟方式不同。

常見狀況

  • 選完答案卻沒顯示對錯：這是正常設計。請完成這批題目並交卷，系統才會統一評分及顯示錯題解析。
  • 按開始沒題目：先確認完整解壓縮，data/ 資料夾仍在；如果選了「還沒作答」，可取消此條件。
  • 音檔不能播放：確認 audio/ 仍在原位置，並主動點擊播放。不要只複製 index.html。
  • 看不到原紀錄：確認使用同一瀏覽器、同一路徑；必要時匯入備份。
  • 想放到網站主機：直接上傳完整網站目錄即可；不需 PHP、Node.js 或伺服器資料庫。

素材與實作

題目、繁中解析及 SVG 插圖為本專案原創。示範音訊由 CMU Flite 經 FFmpeg 預先產生，網站播放時不呼叫外部語音服務。未使用遠端字型、外部 JavaScript 套件或分析追蹤碼。
